题意：

给定一个长为 $n$ 的数列 $a$，求最大的 $\max(a_{l,l+1,\cdots,r})\times\min(a_{l,l+1,\cdots,r})\times(r-l+1)$。

$1\leq n\leq 2\times10^6,1\leq a_i \leq 10^9$。

——————————————————————————————————————————————————————————————————————


稍微想一想贪心就会发现，影响我们最后值的一个很重要的因素是这区间内的最小值。

而它也不是很好求。那就考虑先不管它，假设最小值已经确定了，


那此时要使值最大，就只需要在保持当前最小值不变的情况下使选的值尽可能的多，

因为最小值已经确定了，多一个数一定会使个数加一，最大值可能变大。所以是稳赚不亏的。

到这里，思路已经差不多了。一个很显然的做法是枚举最小值，然后从最小值的位置开始，在保证不会有更小值的情况下，尽可能地向两边扩张。然后在扩展的时候求最大值，或者用一些其他的数据结构求也可以。

但是，很明显，这样子是会超时的，你不可能每一个最小值都拿个while向两边扩展。

所以我们可以用单调栈预处理出扩展最远的地方，然后再用别的数据结构来单独求最大值，差不多能AC。但是内存、时间卡得比较死（比如很多人写了ST表求最大值，然后爆了）

————————————————————————————————想想优化（赛后教练提示了才想到QAQ）——————————————————————————
——————————————————————————————————————————————————————————————————————


所以我们可以接着这个思路继续往下思考一下。

比如这个样例：5 11 15 17 19 3 19 9 4 7

我们发现，当选中的最小值就是整个序列中的最小值，即3时，这个时候时把整个序列选中就是最优的。

当选中第二小值，即4时,此时最优就应该是除了3以外的所有数，但是要求连续，所有3左边的所有都不能选，所以选的就是19 - -  7

同理，当选第三小5时，最优就是5 - - 19    ~~左边的19~~

所以这个序列是不是可以看作被3分成了两个序列，每个小序列中选最小值时的最优序列就是整个小序列。

那每个小序列又可以被它的最小值分成更小的两个序列（当最小值在两侧时是一个）

到这里，你想到了什么？

每个序列是不是像一棵树，最小值就是树根。

诶，到这里，再想想，这样的一个树是不是一个小根堆？对不对

再看看，树根两边的子树是符合原序列的左右顺序的，3左边的数一定在3的左子树

把这两个特征联系在一起，你想到了什么数据结构——笛卡尔树！！！

没错，我们就把原序列建成一棵笛卡尔树。然后对于每个节点作为最小值时，最优序列就是以它为根的树。

最优情况找出来了，我们考虑如何求值，最小值就是根节点。个数可以直接dfs一次，最大值可以在dfs时求出来，甚至算值也可以在dfs时求出来，最后再去求最大值就行了——解决！！！

然后算算复杂度：用单调栈建笛卡尔树O(n),DFS O(n)

综合复杂度：O(n)！！！遥遥领先！

但是！！！但是！！！

在实现的时候会发现很多个问题；

1、 看一眼范围，最大值足足有1e9 * 1e9 * 1e6！直接爆了long long，那就只能用__int128或者打高精了

2、n最大是2e6，当它是一颗斜树时dfs递归的时候会爆栈！（标程就是这么挂了的，别问我怎么知道）

我们想想怎么解决，既然不给递归，但我们又要用递归来求，怎么办捏。

于是乎我想到了用循环来代替递归。

无论是求最大值还是求个数，都是要dfs下去然后返回后来求的。所以我们可以从最底层反推到根。

然后就写出一个类似拓扑的东西（因为一个节点必须要在子节点全部处理完之后才能去处理）

先把叶子结点加入队列，然后一个个处理，处理完就把父节点加入队列。（处理的时候要先判断此节点有没有处理过，它的子节点有没有全部被处理过）

3、2e6的数据还是有一点大，要打输入优化，scanf不够就离谱，然后不想打快读，所以选择给cin打解绑。（标程在这也挂了，标程甚至没到80分，lj东西）

这样就可以愉快的AC了捏！

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef __int128 ll;
const int N = 2e6 + 10;
struct nd
{
	int left;
	int right;
}tree[N];
ll dd[N],d1;
int n,root,vis[N],fa[N];
ll a[N],gs[N],ma[N]; 
ll ans; 
inline void pr(ll x)
{
	if(x >= 10)
		pr(x / 10);
	putchar(x % 10 + '0');
}
queue <int> q; 
int main()
{
	freopen("A.in","r",stdin);
	freopen("A.out","w",stdout);
	ios::sync_with_stdio(0);
	cin.tie(0);cout.tie(0);
	cin >> n;
	int tt;
	for(int i = 1;i <= n;i++)
	{
		cin >> tt;//因为我不想打快读，而且刚输入的时候不大，所以直接cin到int里面，在赋值到__int128里，注意__int128不能直接cin、cout捏
		a[i] = tt;
		while(d1 && a[dd[d1]] >= a[i])
			d1--;
		if(!d1)
		{
			tree[i].left = dd[1];
			fa[dd[1]] = i;
		}
		else//建笛卡尔树
		{
			tree[i].left = tree[dd[d1]].right;
			fa[tree[i].left] = i;
			tree[dd[d1]].right = i;
			fa[i] = dd[d1];
		}
		dd[++d1] = i;
	}
	for(int i = 1;i <= n;i++)
	{
		if(!tree[i].left && !tree[i].right)//把叶子结点加入队列
		{
			q.push(i);
			ma[i] = a[i];
		}
	}
	ll num;
	int t;
	vis[0] = 1;
	while(q.size())//bfs模拟递归回推
	{
		t = q.front();q.pop(); 
        
		if(vis[t] || !vis[tree[t].left] || !vis[tree[t].right])//判断是否符合条件
			continue;
		vis[t] = 1;
        
		if(tree[t].left)
			ma[t] = max(ma[t],ma[tree[t].left]);
		if(tree[t].right)
			ma[t] = max(ma[t],ma[tree[t].right]);
		gs[t] = gs[tree[t].left] + gs[tree[t].right] + 1; //求最大值和个数
		num = ma[t] * a[t] * gs[t];//计算最后的值
		ans = max(ans,num);
        
		q.push(fa[t]);
	}
	pr(ans);//__int128不能cout，只能这样子了捏
	return 0;
}
```
